# 极地风暴 · 北极熊大冒险

一款纯本地、离线可玩的 3D 网页动作游戏。北极熊被空投到南极大陆，迎战 15 道企鹅战线，最终挑战企鹅王。3D 模型全部程序化生成，带实时冰雪粒子、动态天空、极光、暴风雪与程序化音效。

## 运行方式

**最简单**：用 Chrome / Edge 双击打开 `index.html` 即可游玩（无需联网、无需安装任何东西）。

也可以起一个本地服务器（可选，便于调试）：

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> 首次进入战斗后点击画面即可锁定鼠标（自由视角）。若黑屏，请确认浏览器开启了 WebGL（Chrome 设置 → 系统 → 使用硬件加速）。

## 核心系统

- **等级成长**：击杀企鹅获得经验，升级提升生命、攻击、防御、能量；每 3 级获得额外技能点。
- **技能升级**：每通关一关获得 1 个技能点，技能最高 3 级；满级技能可转化为 +2 永久攻击。
- **掉落物**：小鱼（回血 12%）、雪花（+26 能量）、金色小鱼（攻击 +20% 十秒）、北极星石（精英/Boss 掉落，永久攻击 +1）。
- **连击**：2 秒内连续命中会累积连击数，连击越高伤害越高。
- **攻击吸血**：每次攻击命中敌人，均等概率回复 2 / 4 / 6 / 8 / 10 点生命（回满为止）。
- **实体碰撞**：北极熊与企鹅不可互相穿越，靠近会被推开。
- **天气**：部分关卡会遭遇暴风雪——能见度下降、玩家减速、企鹅加速。
- **Boss 战**：企鹅王有三阶段战斗：挥击/滑铲 → 冰息/召唤皇家卫队 → 狂暴暴风雪。

## 技术亮点

- 纯 Three.js r128 + 原生 WebGL，无外部资源依赖，加载即玩。
- 北极熊/企鹅全部程序化建模：顶点噪声“毛皮”位移、PBR 材质、环境反射、实时阴影。
- 南极大陆：噪声地形 + 冰裂缝、冻湖、冰山、远山、雪屋、冰晶、飘雪粒子。
- 障碍物碰撞：岩石、冰晶、雪屋、冰山都是实体，北极熊与企鹅均不可穿越。
- 动态天空 Shader（极昼/极夜循环）+ 极光 Shader + 暴风雪天气。
- 音效全部用 WebAudio 振荡器/噪声实时合成（挥击、咆哮、冰裂、企鹅叫声等）。
- 关卡进度、星级、技能点自动存档于浏览器 localStorage。

## 常见问题

- **页面黑屏 / 只有文字**：浏览器未开启 WebGL，请检查硬件加速设置。
- **想重开进度**：主菜单点击「重置进度」；或开发者工具 → Application → Local Storage → 删除 `polar_storm_save_v1`。
- **画面卡顿**：可调低 `js/models.js` 中地形 `SEG`（第 620 行附近）或关闭阴影。

## 临时测试模式

- **全部关卡开放**：`js/game.js` 顶部 `ALL_LEVELS_OPEN = true`，当前 15 关全部可玩（雪崩技能同步解锁）；改回 `false` 恢复按通关进度解锁。
- **企鹅攻击力倍率**：基础倍率 `ENEMY_ATK_MULT = 2.5`，普通关再降 50%（`ATK_DMG_NORMAL = 0.5`），Boss 关再降 60%（`ATK_DMG_BOSS = 0.4`），可自行调整。
- **企鹅攻击性**：企鹅移动速度 +8%、攻击速度 +30%（冷却/前摇 ×0.7，`ATK_SPEED_FACTOR`）、弹道速度 +30%、贴脸距离更近、Boss 技能间隔缩短。
- **企鹅攻击概率**：攻击意图触发概率降低 30%（`ATK_CHANCE = 0.7`），攻击更快但更不密集。
